# bomellida.github.io
An unofficial Bomellida website.

### Archive Note
The `archivepages.html` section contains a transcription of **Record Group: REG-SOC-HIST-60** (1961-1969). 

If you look at the repository history, you might see that large parts of the archive were changed or rewritten. **The BRUT** (The Bomellida Rediscovery Uncover Team), who are the original discoverers and owners of these records, used an experimental AI software to initially digitize the archives. That software ended up hallucinating a lot of text that wasn't actually there, like "radio broadcasts," "street barricades," and "giving zones."

Since the Archive Pages are just a mirror of the recovered data provided by **The BRUT**, the source code had to be updated to match their new, corrected archive. These updates ensure the pages match the actual 1960s documents: a non-cultural holiday centered on family, warmth, and the exchange of chocolate or sweets.
